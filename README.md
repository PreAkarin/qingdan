# 清单

清单（Qingdan）是一款 Windows 桌面待办清单应用，专注于「打开桌面就能看到今天要做的事」。

> 系统要求：Windows 10 / 11（64 位）。程序不需要 .NET 运行时，所有依赖已打包在单文件中。
> 程序未做商业代码签名，首次运行时 Windows SmartScreen 可能提示「已保护你的电脑」，可选择「更多信息 → 仍要运行」。

- 主界面：未处理 / 紧急 / 已处理三列看板，分类管理、搜索、编辑、右键更新状态。
- 桌面悬浮窗：分类下拉（含全选）、皮肤、背景透明度、显示/隐藏已完成、右键改状态、`+` 快速新增。
- 常驻托盘：关闭主窗口后程序继续运行；托盘可打开主界面、切换悬浮窗、切换开机自启、退出。
- 桌面层级：悬浮窗默认位于桌面底层，可被任何普通窗口覆盖；回到桌面或按 `Win+D` 时仍留在桌面。
- 开机自启：安装或首次运行后默认开启，可在设置或托盘菜单中关闭。

## 安装版

运行 `清单安装程序.exe`：

1. 选择安装位置（默认为 `%LOCALAPPDATA%\Programs\清单`，无需管理员权限）。
2. 点击「开始安装」。程序会创建开始菜单、卸载项和桌面快捷方式，并开启开机自启。
3. 安装完成后可选择立即打开清单。

卸载：开始菜单 → 清单 → 卸载清单，或 Windows「设置 → 应用 → 已安装的应用 → 清单 → 卸载」。
卸载时可选择是否同时删除待办数据。

## 免安装版

直接运行 `清单.exe` 即可，无需安装。

- 可以在任意可写文件夹中运行，也可以移动到其他位置；开机自启会指向当前文件位置，移动后重新运行一次即可更新。
- 免安装版同样会在首次运行后开启开机自启，可在设置中关闭。

## 使用

- 主窗口右上角关闭按钮会隐藏到系统托盘，程序不会退出。
- 悬浮窗右上角的 `齿轮` 打开设置，`—` 隐藏悬浮窗；也可以通过托盘菜单重新打开。
- 悬浮窗顶部下拉框可选择分类；第一项「全部分类（全选）」显示所有分类。
- 点击悬浮窗条目的圆形勾选可完成；右键条目可切换未处理 / 紧急 / 已完成，也可以编辑或删除。
- 点击悬浮窗右侧 `+` 展开快速新增输入框，按 Enter 添加；新增事项会归入当前选择的分类（若选择全选，则为未分类）。
- 双击主界面卡片或点击卡片右上角 `…` 可编辑内容、备注和分类。
- 皮肤与背景透明度在「设置与外观」中调整。

## 数据与备份

数据文件：`%LOCALAPPDATA%\Qingdan\data.json`

每次保存会保留最近一次备份：`data.backup.json`。如果数据文件损坏，程序会自动将损坏文件备份为 `data.corrupt-时间.json` 并回退到默认数据。

## 构建

环境要求：Windows 10/11 x64、.NET SDK 8、PowerShell。

```powershell
# 生成本机离线可用的 .NET 8 运行时包（首次构建需要）
powershell -ExecutionPolicy Bypass -File build\make-offline-runtime-packs.ps1

# 编译、发布单文件免安装版并生成安装程序与发行文件
powershell -ExecutionPolicy Bypass -File build\build-release.ps1
```

产物：

- `dist\清单.exe`：免安装版
- `dist\清单安装程序.exe`：安装程序（与免安装版使用同一份自包含单文件程序）
- `dist\README.md`：本说明
- `dist\SHA256SUMS.txt`：文件校验值
